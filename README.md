# Create Smart Notes 📝

Create Smart Notes is a Flutter-based note-taking application that allows users to create, manage, and organize their personal notes easily.

The app provides a simple and clean interface where users can add new notes, edit existing notes, delete notes, mark notes as favourite, and quickly search through their saved notes.

## Features

- User Authentication using Firebase Authentication
- Create new notes
- Edit and update notes
- Delete notes
- Mark notes as favourite
- View favourite notes separately
- Search notes by title
- User profile information in drawer
- Logout functionality
- Dark mode support
- Firebase Firestore integration for storing notes
- Provider state management


## Technologies Used

- Flutter
- Dart
- Firebase Authentication
- Firebase Firestore
- Provider State Management
- Shared Preferences
- Material UI
